Replaces the sidebar's Workspaces list with the projects you are working in right now. A project appears as soon as it has an open workspace (a chat or an agent) and disappears when you archive its last one, so you never have to hand-pick projects in the sidebar's Project filter.

To turn it on, open Settings → Appearance → Sidebar view and choose **Active projects**. Choose **Default view** there to get Paseo's own list back.

Rows look like Paseo's Workspaces list: project avatars in their colors, a spinning ring while an agent is working, the host badge under each workspace, and how long ago it was active. Projects are listed most recently active first. The sort button next to the "Active projects" heading changes that to the project name, or to how many open chats a project has, and remembers the choice. Click a project to collapse or expand it, and a workspace to open it. The workspace you are in is filled in, and while its project is collapsed the project name is brighter, so you can see where you are.

To get a chat out of the way for a while, right-click it and choose **Set aside for later…**, then **For 1 hour**, **For 3 hours**, **Until tomorrow morning** (9:00) or **Until I bring it back**. The chat leaves its project, and a project with nothing else open drops out of the list. Set-aside chats wait in a **Later** section at the bottom, folded away by default, with the time each one comes back. When the time comes the chat returns to its project on its own. Right-click a chat under Later to bring it back now or change the time. The Later list is kept on the daemon the plugin runs on, so every app connected to it shows the same list, and it survives restarts.

Right-click a workspace (or long-press on mobile) for Copy path, Copy branch name, Rename workspace, Open in file manager and Archive. Open in file manager is offered only for workspaces on the host the plugin is installed on. Pin, Mark as unread and Labels are not available to plugins, so switch to the Default view for those.

Every host configured in the app is included. Background and archived workspaces are left out. Host badge colors come from the app's host settings when the plugin can read them, and are grey otherwise.
