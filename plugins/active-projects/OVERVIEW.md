Lists the projects you are working in right now at the top of the sidebar. A project appears as soon as it has an open workspace (a chat or an agent) and disappears when you archive its last one, so you never have to hand-pick projects in the sidebar's Project filter.

Rows look like Paseo's Workspaces list: project avatars in their colors, a spinning ring while an agent is working, the host badge under each workspace, and how long ago it was active. Projects are listed most recently active first. Click a project to collapse or expand it, and a workspace to open it.

Right-click a workspace (or long-press on mobile) for Copy path, Copy branch name, Rename workspace, Open in file manager and Archive. Open in file manager is offered only for workspaces on the host the plugin is installed on. Pin, Mark as unread and Labels are not available to plugins, so use Paseo's own list for those.

Every host configured in the app is included. Background and archived workspaces are left out. Host badge colors come from the app's host settings when the plugin can read them, and are grey otherwise.
