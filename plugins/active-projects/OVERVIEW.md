Lists the projects you are working in right now at the top of the sidebar. A project appears as soon as it has an open workspace (a chat or an agent) and disappears when you archive its last one, so you never have to hand-pick projects in the sidebar's Project filter.

Projects are listed most recently active first, each with its open workspaces and a status dot (running, needs input, failed, done). Click a project to collapse or expand it, and a workspace to open it. Projects with the same name on different hosts are shown together, with the host beside each workspace.

Every host configured in the app is included. Background and archived workspaces are left out. The list updates live from each daemon and reads only workspace data already available to the app. Plugins can add rows only to the top of the sidebar, so the list sits above Paseo's own Workspaces list rather than replacing it.
